# Dimitar Vitanov — Portfolio

Personal portfolio for Dimitar Vitanov, SEO Research Specialist and computer engineer.

## Stack

Static HTML, CSS, and JavaScript. No build step or tracking scripts. Google Fonts is the only external asset; system font fallbacks are provided.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Deployment

The GitHub Actions workflow publishes this repository to GitHub Pages when changes are pushed to `main`. The repository's **Settings → Pages → Build and deployment → Source** must be set to **GitHub Actions** for first deployment. Expected URL: https://dimivitan01.github.io/Dimitar-Vitanov-Portfolio/

## Editing

Content and metadata are in `index.html`; presentation in `styles.css`; mobile menu and copyright year in `script.js`. Add verified projects to the Selected Work section as they become public. Do not publish client identifying details without permission.
